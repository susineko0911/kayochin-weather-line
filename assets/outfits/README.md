# 服装画像の置き場所

かよちんの画像を PNG または JPEG でここに置いてください。縦長・正方形のどちらでも使えます。

次の名前を使うと、天気に応じて自動選択されます。

- `rain_cold.png` / `rain_mild.png` / `rain_warm.png`
- `cold.png`（最高気温 10℃未満）
- `cool.png`（10℃以上 16℃未満）
- `mild.png`（16℃以上 23℃未満）
- `warm.png`（23℃以上 28℃未満）
- `hot.png`（28℃以上）
- `default.png`（該当画像がない場合）

拡張子は `.jpg`、`.jpeg`、`.png` のいずれでも構いません。雨用画像がないときは、同じ気温帯の通常画像を使います。
